NLP Pipeline Builder

Modular NLP preprocessing and analysis toolkit enabling rapid development of text processing workflows for diverse use cases like sentiment analysis, named entity recognition, and text classification.

Key Features

  • Modular Architecture: Snap-together style NLP components for rapid prototyping
  • Built-in Transformers: Pre-configured pipelines for BERT, RoBERTa, DistilBERT models
  • Data Augmentation Tools: Automated text generation and variation techniques
  • Evaluation Framework: Standardized metrics and confusion matrix visualizations

Quick Start

from nlp_pipeline import Pipeline

pipeline = Pipeline()
pipeline.add("tokenization", "bert-base-cased")
pipeline.add("ner", spaCy_en)
pipeline.add("sentiment", sentiment_roberta)

results = pipeline.run(texts_data)
print(f"Sentiment: {results['sentiment'].mean():.2f}")
